# Прототип покупки внутри VK

Учебная концепция для VK Case Champ 2026. Покупка из поста, каталога и чата, выбор доставки, демонстрационная оплата и статусы заказа.

Магазин и данные вымышлены. Реальные платежи, доставка и авторизация не подключены. Это концепция команды, а не официальный сервис VK.

Сайт в одном index.html: изображения, стили и логика встроены, сборка и зависимости не требуются.
